Tentang pembuat

Belajar sambil membangun proyek nyata.

Website AgroFarm disusun sebagai bagian dari tugas mata kuliah Pemrograman Web / Internet. Seluruh halaman dirancang, ditulis, dan dikodekan secara mandiri menggunakan HTML, CSS, dan JavaScript.

Melalui proyek ini, penulis berlatih menyusun konten yang mudah dibaca, menjaga konsistensi desain, serta memastikan navigasi berjalan baik di berbagai ukuran layar.

Peran dalam proyek

  • Menyusun struktur dan konten setiap halaman.
  • Merancang tampilan dengan CSS dan media query.
  • Menambahkan interaksi dengan JavaScript.
  • Menguji navigasi, formulir, dan tampilan mobile.

Kompetensi proyek

Keahlian yang dilatih

Kemampuan teknis yang diterapkan langsung saat membangun website AgroFarm.

HTML semantik

Menyusun struktur halaman dengan heading, section, article, dan navigasi yang runtut.

CSS responsif

Mengatur tata letak memakai grid, flexbox, dan media query untuk berbagai ukuran layar.

JavaScript interaktif

Menambahkan menu mobile, filter, lightbox, serta animasi saat elemen memasuki layar.

Validasi formulir

Memeriksa isian formulir kontak dan menampilkan pesan kesalahan per kolom.

Media dan lightbox

Menampilkan galeri foto dan pemutar video dengan navigasi tombol serta keyboard.

Aksesibilitas

Menyertakan label, atribut ARIA, fokus yang terlihat, dan dukungan reduced motion.

Proses pengerjaan

Empat tahap penyusunan

Alur singkat dari riset konten sampai pengujian tampilan website.

01

Riset dan penulisan konten

Mengumpulkan materi pertanian, menyusun struktur halaman, lalu menulis ulang dengan bahasa yang mudah dipahami.

02

Perancangan tampilan

Menentukan palet warna, tipografi, dan tata letak agar setiap halaman terasa konsisten dan nyaman dibaca.

03

Pengembangan HTML, CSS, dan JavaScript

Membangun seluruh halaman, komponen navigasi, galeri, video, serta validasi formulir kontak.

04

Pengujian dan penyempurnaan

Memeriksa tautan, tampilan mobile, kemudahan navigasi, dan memperbaiki detail yang kurang pas.

Website edukasi untuk mengenal tanaman, budidaya, teknologi, dan pertanian berkelanjutan di Indonesia.
